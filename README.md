# Financial-Analysis-of-Walmart

Project Overview
This project evaluates Walmart Inc. (NYSE: WMT) using fundamental and relative valuation methods to assess whether the company's stock may be overvalued or undervalued. The analysis was completed as part of an equity valuation and stock-pitch project.

The Excel workbook contains historical financial statement data, valuation calculations, forecasting assumptions, and supporting analysis.
Valuation Methods
The workbook examines Walmart using the following approaches:
- Dividend Discount Model (DDM): Projects future dividends and discounts them to estimate intrinsic value per share.
- Free Cash Flow to the Firm (FCFF): Forecasts operating free cash flow and uses the weighted average cost of capital (WACC) to estimate firm and equity value.
- Free Cash Flow to Equity (FCFE): Forecasts cash flow available to common shareholders and discounts it using the estimated cost of equity.
- Relative Valuation: Examines valuation multiples, including trailing P/E, forward P/E, and price-to-sales, along with the present value of growth opportunities.
- Sensitivity Analysis: Tests how changes in growth assumptions and discount rates affect estimated value.
Methodology and Assumptions
- The cost of equity is estimated using the Capital Asset Pricing Model (CAPM):
  Cost of Equity = Risk-Free Rate + Beta × Market Risk Premium
- The project instructions specify using the 10-year U.S. Treasury yield as the risk-free rate and a 5% market risk premium.
- Forecasts use historical financial information and assumptions about future dividend and free-cash-flow growth.
- The workbook includes supporting notes explaining key projection assumptions.
Valuation estimates depend on the assumptions used. Different growth rates, discount rates, and market conditions can produce materially different results.
